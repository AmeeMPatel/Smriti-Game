# Smriti: The Silent Wake

A narrative-driven horror game with emphasis on atmospheric design, interactive storytelling, and user experience.

## Overview

Smriti is an interactive horror experience built in Unity that explores themes of memory, emotional reconstruction, and exploration. The project focuses on how game UI, environmental design, and interaction systems can work together to create a cohesive, immersive experience.

## What I Designed

### Game UI Systems
- **Main Menu** — Clean, minimal interface that maintains horror atmosphere
- **Dialogue System** — Narrative-focused text presentation with character identification
- **HUD & Feedback** — Sanity indicator and interactive feedback systems
- **Pause Menu & Settings** — Consistent navigation across all menus
- **Scene Transitions** — Visual bridges between game sequences

### Design Philosophy

**Minimal UI = Maximum Atmosphere**
- High contrast elements ensure readability in dark environments
- UI responds to game state (sanity affects visual clarity)
- Every interface element serves narrative purpose

**Interactive System Design**
- Understanding how UI connects to game logic
- Player feedback through visual + audio systems
- Puzzle interaction design that feels intentional

**Environmental Integration**
- UI placement respects spatial design
- 3D asset understanding informs interface hierarchy
- Real-time engine constraints guide design decisions

## Tech Stack

- **Engine**: Unity 6.3 LTS
- **Scripting**: C#
- **3D Design**: Blender (asset creation, environment modeling)
- **UI Framework**: Unity Canvas

## Key Systems

### Sanity System
Visual indicator that changes based on player psychological state. Designed to feel integrated into the game world rather than a UI overlay.

### Dialogue Presentation
Custom dialogue system supporting:
- Character name identification
- Narrative pacing
- Player interaction choices
- Emotional tone through text hierarchy

### Scene Flow
Structured progression through:
- Main menu → Prologue → Dialogue interaction → Narrative reveal → Player choice → Progression

## Design Decisions

**Why Minimal UI?**
Horror games benefit from restraint. Every UI element should earn its place on screen. Visual clutter breaks immersion.

**Why High Contrast?**
Dark horror environments naturally reduce readability. Strategic color and contrast choices make critical information visible without feeling intrusive.

**Why Real-Time Engine Knowledge Matters?**
Understanding Unity's rendering pipeline, performance constraints, and real-time limitations helps designers make informed decisions about UI complexity, animation performance, and asset integration.
